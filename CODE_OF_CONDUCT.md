# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, focus on the work. Harassment, personal attacks and discriminatory language are not tolerated. Reports go to the maintainer by e-mail (see `CITATION.cff`) and are handled confidentially.
